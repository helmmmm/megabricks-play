# Megabricks — Web Build

Play the current browser build at <https://helmmmm.github.io/megabricks-play/>.

Megabricks is an endless vertical 3D Breakout roguelite made in Godot 4.7.1 for the OpenAI Game Jam 2026. The brick volume falls from the ceiling; move the square floor paddle with WASD or arrow keys on desktop, or touch on mobile, and send the balls back upward.

This public repository contains generated Web-export artifacts only. The Godot source project remains private.
